## 1. 本轮做了什么

### W1 · 可靠性补丁（P0）

| 问题 | 处理 |
|---|---|
| F01 改需求后参数切 D，3D 仍在 A | `src/ui.js` 新增唯一提交入口 `commitConfig()`，方案卡 / 快捷键 / 客户改需求 / 重置 / 手输参数 全部走同一条路径；每次提交递增 `cfgRev` 并广播 `wh71:config {id, config, revision, reason}`。`scene71-3d/src/glue.js` 不再监听 DOM 点击，只消费该事件并 `replaceModel()`。 |
| F02 标定弹层内按数字键改背景方案 | 弹层根节点带 `data-wh-modal="1"`；`ui.js` 的全局 keydown 在检测到弹层时直接返回；`calib-ui.js` 在捕获阶段 `stopPropagation()`，双重拦截。 |
| F03 焦点可逃出弹层、关闭后落在 BODY | `calib-ui.js` 实现 Tab/Shift+Tab 循环、`#app` 设 `inert` + `aria-hidden`、记录触发元素并在关闭时 `focus()` 回去。 |
| F05 单图与 3D 可同时选中 | 引入全局唯一 `viewMode = diagram \| sbs \| model`；`updateModeButtons()` 由它派生全部按钮的 `active/aria-pressed`；glue 挂载/卸载后回报 `wh71:viewmode-changed`。 |

### W2 · 首屏入口与信息层级

- 顶栏改为「暂停动效 / 导出预览」两个动作；品牌副标题改为“现场照片与参数化设备预览”。
- 右侧面板标题改为**方案参数**，顶部一排“已应用参数”摘要 chip（型号/跨度/起重量/轨高/工作级别/AGV/示意用时）。
- 新增**现场照片**面板：未添加时给出用途说明 + “选择照片”；已标定时显示缩略图、文件名、像素尺寸、“照片已标定”、重新标定 / 移除。照片入口不再藏在 3D 工具条里。
- 画布下新增**状态条**：模式 · 当前方案 · 参数口径 · 照片状态 · 版本号 `v{n}`。
- 方案卡以“型号”为主标题（编号降为小徽标），第二行是 场景 · 跨度 · 吨位（F14）。

### W3 · 参数草稿 / 校验 / 应用 / 放弃

- 表单只改 `draft`；`appliedConfig`（画布、3D、导出）在点击“应用参数”前不变。
- 草稿条实时列出差异，如“跨度 48.0 m → 60.0 m”。
- 校验统一走 `WH.DATA.validateConfig()`（`src/data.js` 新增）：跨度 (0,150)、起重量 (0,5000)、轨高 (0,80)、AGV [0,20]、工作级别 A5–A8；错误就近显示并聚焦该字段。
- 应用时若能凑成预设（四项全等）就直接落到该预设；否则生成 `自定义` 方案并标“基于 X 的自定义”。
- 有草稿时点方案卡不再静默丢弃，而是弹出三选一：应用后切换 / 放弃修改后切换 / 留在当前。

### W4 · 标定易用性

- 弹层重做为任务区：四步状态条（选择照片 → 标记角点 → 输入边长 → 应用）、右侧信息栏（已选 n/4、已知边说明、当前提示）、底部固定操作区。
- 单点纠错：撤销上一点、点选编号后再点新位置原位替换、重选全部（F10）。
- 照片载入后显示文件名与 `1200×800 px`，仅接受 JPEG/PNG/WebP，读取失败给出可恢复提示。
- 应用成功后：状态条与照片面板同步为“照片已标定（文件名）”，画布保留 3D 实景。

### W5 / W6 · 视图语义、暂停与导出

- 视图按钮改名：示意图 / 3D 预览 / 前后对比；3D 内工具条为 正视·侧视·俯视·45°·完整显示·旋转演示·导出。
- 顶栏“暂停动效”统一停 2D 播放/扫光与 3D 旋转（F12）。
- 导出改为**导出预览**弹层：预览图 + 模式 + 方案 + 关键参数 + 版本 + “沟通示意，非施工依据”；文件名按 `卫华场景71_{示意预览|3D示意预览|照片安装预览|前后对比示意}_{方案}_{日期}.png` 生成；失败有原因与重试（F11）。
- 2D 导出把当前 SVG 栅格化后叠统一水印；3D 导出在 `view3d.exportPNG()` 结果上再叠同一套水印。

### 兼容性

- 2D 单文件版（`node build.js`）不含 3D/标定模块：`3D 预览` 按钮置灰并说明，照片面板改为“当前为 2D 单文件版，不含现场照片标定”，不假提能力。

## 4. 已知限制 / 未做

1. **照片缩放与放大镜（A12）未实现**：标定区目前是“图片自适应窗口 + 直接点击”，坐标换算是整幅线性映射，还没有缩放/平移变换矩阵。
2. **前后对比语义未拆干净（A18）**：仍是“基准方案 A vs 当前方案”，未新增“方案对比”模式。
3. **导出失败模拟（A19）未覆盖**：代码有 try/catch 与错误文案，但没有造异常用例。
4. **对比度审计（A22）**：只按候选令牌统一，未做工具化测量。
5. **3D 内“完整显示”**：非照片模式重置为默认取景（`camRadius=1, zoom=1`），尚未按包围盒精确计算安全区。
6. **快捷键可关闭开关**：本轮用“弹层/输入框作用域”控制，未提供用户级开关。
