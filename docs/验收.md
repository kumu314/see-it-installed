# 验收清单（10 条）

> 每一条都要能在 **现场路演电脑** 上复现，不能只在开发机上成立。

## A. 能不能跑（4 条）

- [ ] 1. 双击 `dist/作品71.html` 直接打开，不需要服务器、不需要联网
- [ ] 2. F12 → Network 全程为空（`www.w3.org/2000/svg` 命名空间不算请求）
- [ ] 3. 控制台无报错、无警告
- [ ] 4. 「播放演示」「跳过动画」「全屏」三个按钮都有效；跳过动画**瞬间**到终态

## B. 演得对不对（4 条）

- [ ] 5. 四步进度条：播放时依次点亮；跳过时一次全亮；每一步的文字随当前方案变
- [ ] 6. 「客户改需求」按钮：3 秒内完成「参数变 → 图重画 → 角标提示」
- [ ] 7. 方案 A/B/C/D 切换：参数卡 **7 个值**（型号/跨度/起重量/轨高/工作级别/AGV/出图用时）全部正确变化
- [ ] 8. 对比滑块：拖到 0%、50%、100% 都不破图、不出现空白条

## C. 上得了台（2 条）

- [ ] 9. 1440×900 与 1280×800 都不错位、无横向滚动条、无元素压字
- [ ] 10. 顶部有「内容创作 / 场景 71 / 归属 活动方」；页面有「示意/推算，非真实设备参数」标注

## 自检命令

```bash

node build.js

# 2) 产物体积与外部引用扫描
node -e "const fs=require('fs');const s=fs.readFileSync('dist/作品71.html','utf8');const ext=(s.match(/https?:\/\/[^\"\s)]+/g)||[]).filter(u=>!u.includes('www.w3.org/2000/svg'));console.log('bytes',Buffer.byteLength(s),'ext',ext.length,ext.slice(0,3))"

# 3) 三个模块是否都在产物里
node -e "const s=require('fs').readFileSync('dist/作品71.html','utf8');['WH.DATA','renderScene','initUI'].forEach(k=>console.log(k,s.includes(k)?'OK':'MISSING'))"
```

## 不合格怎么处理

| 情况 | 处理 |
|---|---|
| 网络请求非空 | 立刻找出 `http` 来源（多半是字体或图片），改内联 |
| 跳过动画后还在跑 | 定时器没清干净，`clr()` 没覆盖到新加的动画 |
| 改需求超过 3 秒 | 砍掉过渡动画，直接切终态 |
| 某方案参数不对 | 数据问题，回 `src/data.js` 查 `configs` |
| 现场电脑打不开 | 用视频备份讲，别现场修 |
