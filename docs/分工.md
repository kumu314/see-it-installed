## 1. 三人分工（按复杂度，不按人头平均）

| 角色 | 负责 | 产出文件 | 为什么给他 |

## 3. 分支与合并

```bash
# 各自开分支
git checkout -b agent/codex/render
git checkout -b agent/a/ui
git checkout -b agent/b/data

# 提交（每完成一个可运行节点就提交，不要憋大招）
git add src/render.js
git commit -m "render: 等轴测厂房 + 门机基础形体"
git push -u origin agent/codex/render
```

**合并顺序**：`data` → `render` → `ui`（依赖关系决定，不能换）。

**合并门禁**：
```bash
node build.js        # 合成 + 三项自检，非零退出就不许合
node docs/check.js   # 验收 10 条（若已提供）
```

**冲突处理**：只允许枯木合并；冲突时以契约为准，不回退契约。
